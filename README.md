# Bechan 💰  
A simple money tracking application to help users manage income and expenses with ease.  

## ✨ Features
- **User Authentication** – secure login system for personal finance tracking.  
- **Income & Expense Logging** – record daily financial activities.  
- **Monthly Summary** – visualize total income and expenses by month.  
- **Tag System** – categorize transactions with tags for better analysis.  
- **Dashboard & Reports** – view financial status at a glance.
